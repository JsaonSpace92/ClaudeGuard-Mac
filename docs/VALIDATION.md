## 性能参考

2.10.3 关闭管理窗口后的一次 30 秒采样，进程物理内存占用合计约 61 MB，CPU 平均约一个核心的 0.1%。WebKit 辅助进程可能保留缓存。

这只是特定系统、网络和窗口状态下的短时观察，不是资源占用上限。RSS 与 physical footprint 是不同口径；没有测量实际 GPU 使用率。

## 重新验证

执行 README 中的本地验证命令。真实断链测试会强制关闭勾选的应用，演练前应结束应用中的任务；自动测试不使用真实应用进行关闭演练。
